# sfarim-og: תמונות שיתוף לעמודי אתר הספרים

**מה זה:** כלי שנותן לכל עמוד HTML באתר הספרים (`yudataub/aaa` = sfarim.kol-toda.co.il) תמונת תצוגה
מקדימה לשיתוף (`og:image`, 1200×630). זו התמונה שמופיעה כששולחים קישור בוואטסאפ.

**איפה הדברים:**
- **התמונות:** בריפו `yudataub/sfarim-og`, בכתובת https://yudataub.github.io/sfarim-og/img/<hash>.jpg.
  הן לא נכנסות ל-aaa, כי הוא כבר 4GB.
- **עותק מקומי של ריפו התמונות:** `site\`.
- **הכלי עצמו:** בתיקייה הזו.

נבנה ב-11.10.2026, ואז קיבלו תמונה 1,120 עמודים.

## הרצה (כשנוספו עמודים חדשים)
```
git clone --bare --filter=blob:none https://github.com/yudataub/aaa.git C:\tmp\aaa-og.git   (פעם אחת; אחרת: git -C C:\tmp\aaa-og.git fetch origin main:main)
python scan.py            # מלאי -> pages.json (מוריד רק את קבצי ה-html)
python build.py           # מייצר תמונות חסרות ב-site\img ומדפיס כמה עמודים ישתנו
python build.py --push    # דוחף את התמונות, ואחר כך commit אחד ל-aaa/main
```
- **`PYTHONIOENCODING=utf-8`:** בלי זה ההדפסה בעברית נכשלת.
- **אחרי `--push`:** הדמון `github_autosync.py` מוריד את העמודים שהשתנו לתיקייה המקומית (`pull_remote_edits`).

## כללים
- **עמוד שכבר יש בו `og:image` לא נוגעים בו.** משתנה רק ה-`<head>`: בלוק תגיות לפני `</head>`, עם ההערה
  `<!-- share preview: C:\sfarim-og -->`. אחרי הדחיפה נבדק שהסרת הבלוק מחזירה בדיוק את הקובץ המקורי.
- **לא מטופלים כאן:**
  - דפי התיקייה שהסנכרון מייצר (`GEN_MARKER`) והעמוד הראשי: הם מקבלים תגיות מ-`github_autosync.py` (`OG_IMAGE`).
  - `privacy.html` ו-`editor/`.
- **בחירת התמונה (`plan()`):**

  | עמודים | תמונה |
  |---|---|
  | שיעורי יוטיוב | תמונת הסרטון |
  | תמלולים | הסרטון של השיעור באותו שם |
  | פרשת השבוע | כריכת "שיעורי קול תודה" של החומש, לפי מספר התיקייה (001–054). מ-055 ומעלה: מועדי השנה |
  | תנאים | כריכת "כה עשו תנאינו" |
  | השאר | כריכת "ספרי הרב יהודה טאוב" |

  הכריכות נלקחות מ-sfarim.kol-toda.co.il/covers/.
- **שם הקובץ** הוא hash של נתיב העמוד. תמונה שכבר קיימת לא נוצרת מחדש. כדי לשנות תמונה, מוחקים
  אותה מ-`site\img` ומריצים שוב. לא לשכוח שוואטסאפ שומר במטמון לפי כתובת.
- **שמות עם `?`** תקינים בגיט ונדחים ב-Windows, ולכן הכלי עובד על clone מסוג bare עם
  `core.protectNTFS=false` ולא על עותק עבודה.
- **`DESC`** בראש `build.py`: תיאור קבוע לעמודים שהפסקה הראשונה שלהם אינה תקציר. למשל "כה עשו תנאינו",
  שנפתח בסיפור הראשון.
